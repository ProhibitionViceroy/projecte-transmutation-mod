# ProjectE — Transmutation Mod

[![Download Latest](https://img.shields.io/github/v/release/ProhibitionViceroy/projecte-transmutation-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/ProhibitionViceroy/projecte-transmutation-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

Assign EMC values to every item and transmute materials into anything of equal energy value.

## Features

- Philosopher's Stone for instant transmutation
- Klein Stars to store millions of EMC energy
- Transmutation Table: exchange any item for another
- Dark Matter and Red Matter tier tools and armor
- Automated collection with Collectors and Relays

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
